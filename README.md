# GAIA 高校地学

<img src="icons/icon-192.png" width="96" alt="GAIA のアイコン：断面を切り出した地球（地殻・マントル・外核・内核）">

地図・断面図・シミュレーション・天体の図と問題演習で、現象のつながりから理解する高校地学アプリ（試作版 v0.1）。
[CELESTIA](https://github.com/kurowasan3/CELESTIA)（高校物理）と同じ仕組み（復習・自動採点・同期・オフライン・問題管理表からの取り込み）で、物理シミュレーションの代わりに「探究」の5ページを持っています。
iPhone・iPad・PC のブラウザで動き、ホーム画面に追加するとアプリとして使えます（PWA）。

## いまできること

- **探究（5ページ）**：解いた問題の「探究で確かめる」から、その内容のページが開く
  - **地図・画像からの識別**：岩石（ルーペで見た組織。火成岩・堆積岩・変成岩 17種）、化石（15種・時代の表）、天気図（6つの気圧配置）、地形図（等高線 7種。2点をタップすると地形断面図）。それぞれ「図鑑」と「クイズ」。火成岩の分類表、造岩鉱物
  - **地層・地質構造の理解**：断面図で地史を1つずつ再生（堆積・傾斜・褶曲・断層・不整合・岩脈・深成岩の貫入と接触変成。7つの型 × 乱数で無数の例）。断面図からできごとを古い順に並べる練習。柱状図の対比（鍵層）
  - **地球現象のシミュレーション**：地震波の広がりと地震計の記録・3観測点での震央決定・走時曲線／断熱変化とフェーン現象（凝結高度・雲・気温のグラフ）／ホットスポットと火山島の列（プレートの向きの変化）／アイソスタシー（山の根・氷床と隆起）／放射年代（半減期）
  - **天体・宇宙の可視化**：天球と日周運動（緯度・赤緯・時刻を動かす、南中高度・昼の長さ）／惑星の見え方（離角・内合・衝・会合周期・金星の満ち欠け）／月の満ち欠け（南中時刻）／ケプラーの法則（面積速度一定）／HR図（29の恒星、L＝R²T⁴ の計算、恒星の一生）
  - **地学用語の関連付け**：632語の用語が「原因 → 結果」「対比」「証拠」「できる」などの関係 704本でつながる。用語のつながりの図、関係を当てる練習、2つの用語をつなぐ経路さがし、単元ごとの一覧。教科書の古い言い方（塩基性岩・コリオリの力など）でも検索できる
- **出題形式（6つ）**：一問一答（語句。別名・表記ゆれを吸収）、正誤・選択（1つ・すべて）、図の読み取り（天気図・地形図・断面図・岩石・化石・グラフ）、順序・新旧（並べかえ）、用語の関係、計算（有効数字で判定）。記述は自己採点
- **問題 299問**：全26単元・基礎〜国公立2次（基礎 56・標準 123・入試基礎 91・国公立2次 29）。図つき 38問（図は探究と同じモデルから作る）。難関・最難関は問題管理表から取り込む前提
- **法則 27件**（地層累重・切断・大森公式・アイソスタシー・断熱減率・凝結高度・南中高度・ケプラー・会合周期・シュテファン・ボルツマン・ウィーン・等級と距離・ハッブル・放射年代など。導出または根拠つき）、概念 61、誤概念 24
- **全分野からランダム／形式ごと／単元ごと／復習／検索／問題セット（3つ）**、自信度、定着度、ライト・ダーク、アカウントと同期、オフライン（CELESTIA と同じ）
- マスコット：モグラの「ライエル」（地層を掘って調べる。名前は『地質学原理』のライエルから）

## データの正しさを守る仕組み

次の検査を通らないとビルドが失敗します（`node tests/run.mjs`）。

- **探究のモデル**（`tests/lab.test.mjs`）：正断層で上盤が下がる・逆断層で上がる、侵食・傾動・接触変成、どの地史の型でも断面が作れて岩脈と断層が交わる、円錐の等高線が円になる、冬型で等圧線が南北に混む、南中高度 ＝ 90° − φ + δ、夏至（北緯35°）の昼が約14.3時間、すべての惑星で P²/a³ ≒ 1、白色矮星は小さく超巨星は大きい、など
- **問題の図**：作図仕様（`*.fig.json`）から作り直した SVG が今のものと同じか（`node tools/geofig.mjs --check`）
- **答えの整合**：すべての「入力用の答え」が読め、正解を入れると正解になるか
- **参照**：問題から探究へのリンク（岩石・化石・天気図・地形図・地史の型・用語）、概念・法則・誤概念、用語のつながり

## フォルダ

```
content/                 正規データ（マスター。ここを編集する）
  taxonomy.json          分野（固体地球・地層と歴史・大気と海洋・宇宙）・単元 26（ID 固定）
  concepts.json  laws.json  misconceptions.json  tags.json  collections/
  geo/                   探究のデータ
    identify.json        岩石（組織・鉱物の割合・説明）、造岩鉱物、化石（時代・環境）、天気図・地形図の一覧
    sky.json             恒星（表面温度・光度・スペクトル型・絶対等級・距離）、惑星、天球で動かす天体
    terms.json           用語（単元・説明）と、用語どうしの関係（種類・説明）
  problems/<分野>/<問題ID>/problem.json（図があれば <図>.fig.json と <図>.svg）
data/                    アプリ用（生成物。tools/build_data.py が作る。手で編集しない）
js/                      アプリ（app.js・lab.js（探究）・catalog.js・answer.js（採点）・parser.js・sync.js …）
  lab/                   探究の5ページ（identify・strata・phenomena・sky・terms）
  lab/model/             画面に依存しないモデル（strata：地史と断面、maps：等値線・天気図・地形図、specimens：岩石と化石の絵、charts：走時曲線・HR図）
tools/                   変換・作図・検査（geofig.mjs：問題の図／import_items.py：問題管理表の取り込み）
tests/                   検査（node tests/run.mjs）
docs/data-spec.md        データ仕様
supabase/schema.sql      同期用の表（Supabase の SQL Editor で1回実行）
```

## 問題を追加・修正する

```sh
pip3 install jsonschema
node tools/geofig.mjs                    # 作図仕様（*.fig.json）から SVG を作る
python3 tools/build_data.py              # content/ → data/
python3 tools/validate_content.py --write-golden   # 新しい問題ID を台帳に足す（問題を足したとき）
node tests/run.mjs                       # 検査（全部 ✓ になればOK）
```

1. `content/problems/<分野>/<新しい問題ID>/problem.json` を、既存の問題をまねて作る（形は [docs/data-spec.md](docs/data-spec.md)）
2. 断面図・天気図・地形図・岩石・化石・走時曲線・HR図は、作図仕様（`*.fig.json`）を書くと探究と同じ見た目の SVG ができる。ほかの図は SVG を直接置く
3. 上の4行を実行
4. `content`・`data`・`tests` フォルダごとリポジトリにアップロード

規則：問題ID は変えない・消さない（消すと台帳 `tests/golden/ids.txt` との照合で検査が失敗する）。出さない問題は `quality.status` を `hidden` に。

## 問題管理表からの取り込み（難関・最難関）

問題管理表の形式（1問1フォルダの `item.json`・`problem.svg`・`solution.svg`）で作った問題は、次のコマンドで content/ に取り込める。

```
python3 tools/import_items.py <content フォルダ> --sheet GAIA問題管理表.xlsx --verify <verify フォルダ>
node tools/geofig.mjs && python3 tools/build_data.py && python3 tools/validate_content.py --write-golden && node tests/run.mjs --e2e
```

- 問題ID は item.json の id をそのまま使う（同じ ID は上書き）。単元は単元名で決まる（「地層」「断熱変化」「恒星」などの略称も可。`ALIASES`）。
- 難易度 1〜5 は level 基礎・標準・国公立2次・難関・最難関に対応させる。
- 問題文の enumerate が小問、答えの「(1) … (2) …」が小問ごとの答えになる。入力採点はしない（自己採点）。
- item.json に `format`（`qa` `choice` `figure` `order` `term` `calc` `written`）を書くと「形式ごとに演習」に出る。無ければ記述。
- 概念はタグ・テーマ・核の語から自動で付ける（最大3つ）。
- 検証スクリプトは `verify/<ID>.py` に置く（アプリでは使わない）。

## アカウントと同期（Supabase）

- Supabase プロジェクトは **Lemma と共通**（`js/config.js` の値も同じ）。アカウントも共通で、記録は別の表 `gaia_state` に保存
- 準備：`supabase/schema.sql` を SQL Editor で1回実行（表を1つ足すだけ。ほかのアプリの表には触れない）
- 退会はアカウントごと消すので、Lemma などの記録も消える（画面でもそう伝えている）
- 端末の保存キーは `gaia.v1`・`gaia.auth`。同じドメインの Lemma・ぶつりば・CELESTIA・ALCHEMIA と混ざらない

## GitHub Pages で公開する

リポジトリの直下にこのフォルダの中身を置き、Settings → Pages で `main` / `/ (root)` を選ぶと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

- 更新したときは `sw.js` の `VERSION` と、各 JS の `FILE_VERSION`、`css/style.css` の `--gaia-version` を同じ値に上げる
- オフライン用のキャッシュ名は `gaia-` で始まり、消すのも `gaia-` のものだけです（同じドメインのほかのアプリのキャッシュを消さない）
- 天気図・地形図・断面図は学習用の模式図です（海岸線・気圧の値・地形は単純化してある）
